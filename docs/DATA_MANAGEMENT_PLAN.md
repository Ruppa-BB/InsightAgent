# D阶段：数据管理扩展计划

规划日期：2026-10-03。用户确认六项全部纳入：资产目录、质量管理、导入批次、指标口径、基础血缘、质量问题处理。本阶段接在已验收M1之后；制造业M2与类帆软扩展暂缓，最终PRD目标保留。

## 工期与目标

单人学习开发，每天3～5小时、每周5天：20个开发工作日（60～100小时），另留3～5个工作日返工缓冲，总计约5个自然周。不是按工具执行速度推算承诺；新需求、学习深度和数据问题可能顺延。不指定开工日，D1是实际开始后的第一个工作日。

目标闭环：源文件登记 → 批次校验与清洗 → 隔离数据集导入 → 资产/指标查询 → 质量问题登记与复核 → Agent分析 → 报告追溯。

现有Online Retail II分析数据作为基线保持可用。复用FastAPI、Pydantic、SQLAlchemy/PostgreSQL和现有前端；应用元数据先沿用SQLite并做可升级迁移，不在本阶段同时重写前端或迁移全部历史存储。元数据归属数据集/版本，凭证仅引用配置，不写入可导出目录。

## 范围与验收

| 模块 | 本阶段交付 | 验收要求 |
|---|---|---|
| 资产目录 | 已注册数据集/表/字段、类型、行数、主外键、人工业务说明、检索和刷新 | 自动技术元数据与人工说明分开；刷新不覆盖说明；只扫描注册的允许表，不暴露系统表/凭证 |
| 质量管理 | 复用8项规则，配置受控阈值、检查历史、规则版本、问题样例 | 结果可复算；样例数量受限；异常停止/警告按规则明确，保存失败不可假装成功 |
| 导入批次 | 本地文件登记、SHA256、解析/清洗统计、状态/日志、隔离导入、重复检查 | 重复批次不重复写入；失败不部分发布；已有历史统计标注来源及可信程度 |
| 指标口径 | 定义查看、版本化说明草稿、校验/发布、分析引用版本 | 可改说明及允许配置；公式从既有白名单选择；禁止任意SQL公式；历史引用不被新版本覆盖 |
| 基础血缘 | 手工声明+任务登记的文件→产物→表→指标→分析/报告关系、上下游查询 | 每条边有来源/版本；未登记显示未知；不声称自动解析全部SQL；历史绑定当时版本 |
| 问题处理 | 规则失败建问题、状态/备注/事件记录、复检关联和关闭 | 重复检查不刷重复未关闭问题；关闭需复检证据或明确人工豁免原因；不自动修业务数据 |

导入首版只支持现有Online Retail II约定结构的Excel/清洗CSV，可通过受控本地任务运行并在页面跟踪；不承诺任意Excel自动映射或多源同步。读取原始Excel需要时才添加读取依赖，并记录锁文件变更。文件大小/行数预算按实测明确；前端请求不等待百万行导入完成。

隔离导入使用固定受控目标schema/数据集版本，不把上传名称直接拼进SQL。通过校验后显式选择为可分析版本，切换不重写基线数据；Agent只查询已发布且允许的数据集。旧分析/报告绑定原版本，未有证据的旧记录显示来源未知或基线登记，不伪造历史批次。

## 每日任务

| 工作日 | 工作任务 | 当日验收 |
|---|---|---|
| D1 | 数据管理需求字典、注册表清单、实体模型和迁移方案 | 明确dataset/version/asset/batch/check/issue/metric/lineage关系；基线回归通过 |
| D2 | 元数据存储迁移、稳定ID、数据集注册与只读扫描API | 旧历史仍能读取；重复扫描不重复建资产 |
| D3 | 字段字典、人工说明编辑、表关联和搜索 | 刷新不覆盖人工说明，未知说明不猜测 |
| D4 | 数据管理首页、资产详情与Agent入口关联 | 可查五张业务表及字段，并跳转对应指标 |
| D5 | 质量规则注册、配置版本与检查记录 | 现有规则数值一致；无效阈值拒绝 |
| D6 | 问题样例、规则详情、检查历史与对比 | 同数据集/版本才对比；样例有上限 |
| D7 | 质量检查页面、门禁和失败状态 | 主分析沿用质量门禁，检查故障明确显示 |
| D8 | 批次登记、文件指纹、已有统计来源标注 | 重复文件可识别；导入历史未知不冒充新记录 |
| D9 | 复用清洗流程、预检、统计与任务状态 | 明确过滤规则及统计重叠；计数能够解释 |
| D10 | 隔离导入、事务发布、失败清理与重跑 | 小样本失败回滚；重跑无重复；主数据未变化 |
| D11 | 全量导入验证、页面批次追踪与版本选择 | 百万行数据计数/金额核对；任务状态和日志可见 |
| D12 | 指标注册、现有口径快照与版本引用 | 单位/公式/维度/过滤一致；旧分析能识别口径 |
| D13 | 指标草稿、允许配置校验、发布/停用流程 | 无效或任意SQL拒绝；发布新版本不覆盖旧版 |
| D14 | 指标管理页面、分析/报告证据展示 | 用户可从答案回到实际指标版本 |
| D15 | 血缘节点/边、导入和指标发布登记 | 可沿源文件追踪至表和指标；未知边明确标记 |
| D16 | 血缘查看、上下游影响与历史来源绑定 | 两次版本导入不混淆；历史报告不指向新批次 |
| D17 | 质量问题建单、去重、状态及处理事件 | 重复检查保留同一未关闭问题并追加检测记录 |
| D18 | 复检与关闭、人工豁免、问题处理页面 | 未复检不能伪称修复；失败复检不关闭 |
| D19 | 全链路API/浏览器验收与故障测试 | 导入→质量→处理→发布→Agent→报告来源全部可追溯 |
| D20 | 回归、启动说明、演示脚本、学习笔记与验收记录 | 原M1能力不退化；按证据列出完成与未通过项 |

每个工作日保留概念讲解与记录时间。测试规模按行为需要确定，不预设新增测试数量；批次幂等、发布原子性、版本一致、质量问题复检及旧记录兼容必须验证。
