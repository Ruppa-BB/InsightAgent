## 阶段一目标

输入“为什么 2011 年 2 月销售额比 1 月下降？”，系统能解析问题、调用受控数据工具、查询真实 PostgreSQL、核对客户/产品/国家贡献、生成图表和有证据的回答，并保存分析结果。

```text
自然语言问题
→ 指标/期间解析
→ Agent 规划
→ 受控 SQL Tool
→ 真实查询和贡献核对
→ 图表与解释
→ 保存结果
```

本阶段单用户、本地 PostgreSQL、一个 LLM。优先完成 Agent 行为；页面只做最小呈现。最终 PRD 中其余能力均保留为后续阶段目标。

## 日常节奏

建议每天用 30 分钟读当天概念，2～3 小时实现，30～45 分钟自己运行和解释结果，最后 15 分钟记下今天学到的内容。每个步骤由用户动手；助手负责讲解、拆解问题和检查结果，不一次性代写整阶段。

## 时间控制与降级

出现延期时按顺序缩小交付：

1. 前端降级为 Swagger 或命令行；Agent 主链继续保留。
2. 用固定分析策略替代 LLM 自由规划，但保留 LLM 问题解析和工具调用。
3. 首版只分析客户和产品，国家维度列为可选。
4. 图表先输出可读的表格或 Mermaid/静态图，不为前端图表阻塞 Agent。

不能删掉的核心学习目标：Agent 至少主动调用一个数据库工具；查询真实数据库；回答引用工具结果；归因可以对账。
