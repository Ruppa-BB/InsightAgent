# N6 经营总览

N6 接通「无需提问发现变化 → 点击提醒 → 两期比较 → 三维贡献 → 保存与反馈」。使用 Online Retail II 零售样本，单位 GBP；没有成本及毛利。

## 行为与口径

- GET `/api/dashboard` 默认选择覆盖范围内最新完整月，当前为2011年11月；也可指定 `?month=2011-02-01`。部分月份拒绝，空数据和质量规则失败分别提示。
- 六张卡：销售额、订单数、客户数、销量、客单价、加权平均售价。展示当月与上月变化；基期覆盖不足、无记录或零基数时不输出比例。
- 最近最多12个月销售额趋势与可展开明细。Top客户/商品使用当月销售额，在数据库中全量分组后降序取10，金额相同按代码排序；不使用先按代码截断再排序。
- 提醒复用N5：环比下降严格超过20%，或偏离前三个连续完整月份均值严格超过20%。不代表因果、未消除季节性或月份天数影响。
- 每个触发月份一个按钮，携带销售额、当前月、上月、月份维度和空筛选，调用已有结构化分析API；移动平均提醒点击后也是比较上月，按钮明确说明，移动平均基线保留在查询依据中。
- 总览指标、排行、质量及检测共享同一只读 REPEATABLE READ 数据库快照。页面可查看查询依据和数据版本。点击分析会读取新的数据库快照，固定样本可复现；数据改变后不保证新分析等同旧总览，不属于跨请求快照重跑。
- 不调用模型、不自动训练、不新增框架；沿用现有白底珊瑚红页面。当前总览只支持全数据，筛选与组合下钻安排在N7。
