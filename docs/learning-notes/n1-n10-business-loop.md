# N1～N10：经营闭环学习知识点

学习目标：让模型提出受控参数，由工具查询可信数据，再给出可以复核、保存和重开的结果。

| 知识点 | 项目中的含义 |
|---|---|
| 语义层 | 指标规定公式、单位和有效订单口径；维度规定如何分组 |
| 参数化与白名单 | 日期等值用绑定参数；SQL结构只能从允许指标、维度和筛选中选择 |
| 解析与执行分离 | 模型输出结构化计划，Pydantic校验后工具执行；解析正确率与标准计划执行正确率分别统计 |
| 完整贡献 | 两期对象取并集，新增和消失都计算；各维度分别解释总差额，不能跨维度相加 |
| 连续下钻 | 保存父分析、期间和筛选；明确操作可直接调用工具，不必每次花钱问模型 |
| 数据质量与覆盖 | 日期边界完整不等于无缺失；不完整月份、零分母、基期不足应明确返回状态 |
| 异常提醒 | 阈值和过去月份均值用于发现变化，不证明经营原因 |
| 固定策略Agent | 按允许策略组织工具步骤；有累计步骤、时间、调用和token预算，失败可追踪 |
| 反馈 | 幂等保存避免重复，revision记录更新；用户反馈不自动成为事实或模型知识 |
| 快照报告 | 同次只读事务读取一致数据，保存原文和证据哈希；重开与导出不重新查库 |
| 验收与故障注入 | 工程测试、标准问题、浏览器演示分开取证；故障注入验证提示，不能冒充真实事故 |

当前数据是零售样本GBP，未提供成本与毛利。下一阶段学习制造业数据建模、历史成本快照、合成异常真值和明细/汇总对账。完整本轮结果见 [N10验收](../ACCEPTANCE_N10.md)。
