## 练习评分

| 分数 | 标准 |
|---|---|
| 0 | 不会或把方案说成已实现 |
| 1 | 能复述答案，但不能解释术语 |
| 2 | 能举例并说明边界 |
| 3 | 能定位代码、动手SQL、应对追问 |

第1轮只读题不读答案，第2轮听追问，第3轮打开项目演示。目标是每题至少2分，必背题和10道SQL至少3分。
